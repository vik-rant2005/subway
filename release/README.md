# Dayline Android release

**APK:** `Dayline-v1.0.1.apk`  
**Version:** 1.0.1 (version code 2)  
**Application ID:** `com.vikrantbhan.dayline`  
**Device build:** Android arm64 (Pixel 8 compatible)  
**SHA-256:** `ad83cf37270e4fdda84ffdf5e529cfeb8e3373d9c127f8af6d911d9f2c1b3d44`

This release starts with an empty board and removes only bundled demo entries from existing app data. Completed departures are struck through and show a red station marker.

## Publish on GitHub

Create a GitHub Release and attach `Dayline-v1.0.1.apk` as a release asset. On the Pixel 8, download the asset, open it from Downloads, and approve installation for the app that opened it if Android asks. It uses the same application ID and release signing key as version 1.0.0, so it can upgrade that install.

The APK has a dedicated Dayline release signature. Back up the signing files listed in the project README privately. Do not upload them with the APK.
